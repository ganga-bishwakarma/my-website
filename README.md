## About this Repository

This is the source repository for [gangabishwakarma.com.np](https://www.gangabishwakarma.com.np), a single-page personal website built with vanilla HTML, CSS, and JavaScript. No build step, no framework, no dependencies.

## Technical Stack

- **Code:** Vanilla HTML5 + CSS3 + JavaScript (no frameworks, no build step)
- **Hosting:** GitHub Pages
- **DNS & CDN:** Cloudflare
- **SSL:** Cloudflare (automatic)
- **Email:** Zoho Mail (`contact@gangabishwakarma.com.np`)
- **Contact:** WhatsApp-first

## Brand System

- **Colours:** Warm Beige (#F3D5B5), Soft Pink (#FF8FA3), Charcoal (#2C2C2C), Lavender (#CDB4DB, RAW TALK only), Ivory White (#FAF9F6)

- **Merry El's section uses:** Champagne Gold (#C5A46D), Ivory Cream, Soft Blush
- **Hunate Movement section uses:** Prana Red (#B83A2D) as accent
